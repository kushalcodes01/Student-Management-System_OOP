Student Management System (SMS) V3

A command-line Student Management System built using Python and Object-Oriented Programming (OOP). This project allows users to manage student records with features such as adding, viewing, searching, updating, deleting, and storing student data persistently.

Features
Add new students
View all students
Search student by ID
Search student by name
Update student details
Delete student records
Count total students
Display semester-wise statistics
Input validation
Duplicate ID prevention
Persistent storage using file handling
Modular project structure using multiple Python files
